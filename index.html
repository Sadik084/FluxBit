Built for the transfer

Small app.
Serious engine.

A compact interface around the parts that matter: fast transfers, resumability, task control, connection management, and a clean Windows experience.

Multi-segment HTTP

Large HTTP(S) transfers can be split into byte ranges and downloaded concurrently for high throughput.

Resume built in

Transfer state is retained so interrupted downloads can continue without unnecessarily starting again.

BitTorrent

Native torrent downloading with task, peer and seeding controls inside the same desktop application.

Smart retries

Recoverable transfer failures can be retried while the download engine manages connection activity.

Task inspector

See useful task information such as source links, saved paths, sizes, progress, speeds and connection data.

Tray + browser bridge

Keep FluxBit running quietly and use its browser integration to hand supported links to the desktop app.

Under the sketch

The interface stays compact while transfer work happens in the background. HTTP downloads use segmented asynchronous work, while torrent tasks use the native torrent engine.
